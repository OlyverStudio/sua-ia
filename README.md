# Sua IA, explicada de forma simples

Página da **Olyver Studio** que explica, para dono de pequeno negócio, o que é um agente de IA de atendimento — sem jargão, sem "LLM", sem "modelo de linguagem".

**[▶ Ver no ar](https://olyverstudio.github.io/sua-ia/)**

![Preview da página](./preview.png)

## Por que essa página existe

Vender agente de IA para comércio local esbarra num problema anterior ao preço: **a pessoa não sabe o que está comprando**. "IA" virou palavra genérica, e o dono da loja não consegue distinguir um chatbot de menu fixo de um agente que conversa de verdade.

Esta página resolve isso antes da conversa comercial. O link é enviado antes da reunião: o cliente chega sabendo o que é, e a conversa começa em "quanto custa" em vez de "mas o que é isso".

## Estrutura

- **Explicação em linguagem comum** do que o agente faz e do que não faz
- **Página de valores** (`valores/`) separada, para que o preço não seja a primeira coisa que a pessoa vê
- Chamada para conversa com a Olyver Studio

## Notas técnicas

Duas páginas estáticas em HTML e CSS, publicadas por GitHub Pages. Material comercial precisa carregar instantaneamente no celular de quem clicou num link do WhatsApp — é o cenário de uso inteiro.

## Rodando localmente

```bash
git clone https://github.com/OlyverStudio/sua-ia.git
cd sua-ia
```

Abra o `index.html` no navegador.
